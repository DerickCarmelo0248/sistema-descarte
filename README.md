# Sistema de Descarte de Equipamentos

Sistema web desenvolvido para controlar e documentar o processo de descarte de equipamentos de informática.

## Objetivos

- Substituir o controle realizado por planilhas;
- Centralizar os registros de descarte;
- Permitir rastreabilidade por patrimônio;
- Armazenar comprovantes, fotos e documentos;
- Gerar relatórios por período, unidade e tipo de equipamento.

## Status

Projeto em desenvolvimento.
